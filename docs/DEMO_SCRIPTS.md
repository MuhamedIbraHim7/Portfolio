# Suggested project demos

These are recording outlines for future media. Use a separate test environment and identify simulated services on screen. Publish a clip only after the depicted data and system have been cleared for sharing.

## AI Sales Lead Engine · about 60 seconds

| Time | Action and narration |
| --- | --- |
| 0–10 s | Show a synthetic Arabic property inquiry and a salesperson’s question. “Who should I call first, and what supports that priority?” |
| 10–25 s | Trace the inquiry from intake through identity normalization. Replay the synthetic event and show how the duplicate is handled. |
| 25–40 s | Show the quoted budget evidence, the normalized field and the deterministic qualification result. Explain how uncertain values go to review. |
| 40–55 s | Show the synthetic lead in the ranked callback queue. Point to the reason for its priority. |
| 55–60 s | Open the offline scenario log and name its scope. Keep the distinction between simulated and live CRM calls visible. |

## Multilingual RAG Assistant · about 60 seconds

| Time | Action and narration |
| --- | --- |
| 0–12 s | Pick one question from the public paired evaluation and show its expected passage ID. |
| 12–28 s | Run the original question and a paraphrase against the same sample. Show the retrieved passages and how their ranks differ. |
| 28–43 s | Explain why close scores can trigger reranking. Show the passage that grounds the answer or the low-confidence fallback. |
| 43–60 s | Open the stored evaluation report. In the paired sample, the expected passage ranked first for 95 original questions and 80 paraphrases out of 100. Explain what this measures. |

## Real-time Voice AI · about 45 seconds

| Time | Action and narration |
| --- | --- |
| 0–10 s | Introduce the cleared demo environment, speakers and synthetic support question. If recording the professional system is unavailable, record a narrated architecture walkthrough and label it accordingly. |
| 10–25 s | Follow a single turn from client audio through WebSockets, speech processing and the conversational service. |
| 25–38 s | Show how the spoken response returns to the user. Explain where transport, turn detection and speech processing affect the experience. |
| 38–45 s | Identify the observed behavior. Include latency only alongside an approved measurement method, test conditions and result. |

Keep the original recording away from the public repository until reviewed. Export a captioned MP4 or add a hosted video link and describe it in the case study’s media list.
