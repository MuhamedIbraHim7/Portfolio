Overview

Finding the right paragraph in a collection of Arabic PDFs can take longer than answering the question itself. At Neqabty, I designed a retrieval system that brings source passages into the conversation.

The problem

Users need to verify an answer against the original document. A plausible response is difficult to trust when they cannot locate its source.

Who it serves

Users of syndicate services searching information held in Arabic documents.

My contribution

I architected the Azure retrieval system, built custom embedding pipelines and worked with the backend and mobile teams on delivery.

System design

Document Intelligence extracts text, an embedding pipeline makes passages searchable, and Azure AI Search supplies relevant context to GPT-4o for a cited response.

Tools & components

  • Azure AI Search
  • Document Intelligence
  • GPT-4o
  • Azure OpenAI

Results & trade-offs

Deployed across five syndicates, as reported in my CV.

Implementation decisions

The answer depends on the quality of both text extraction and search. A citation makes the supporting text available for a reader to inspect.

Testing & reliability

Useful evaluation cases include imperfect PDF extraction, a question with several plausible passages and a question the documents cannot answer. Client documents and example queries stay private.

Data handling

In a deployment with different document permissions, retrieval needs to enforce access before passing text to the model. Public examples would require documents cleared for sharing.

Next steps

I would build an Arabic evaluation set from material cleared for publication and score passage retrieval separately from citation accuracy.
