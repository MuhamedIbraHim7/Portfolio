AI Sales Lead Engine.

Turns Arabic sales inquiries from three channels into one ranked HubSpot queue. Each lead carries a reason for its priority.

Automation

Overview

A property buyer can fill in a form, message an agent in Arabic and change their budget before anyone calls back. I built a workflow that keeps those conversations together and gives a salesperson a reason to make the next call.

The problem

An inquiry that arrives twice can become two deals. A colloquial budget or a request to be called later can also disappear when the conversation moves between channels.

Who it serves

Real-estate sales representatives who need to decide which buyer to contact next.

My contribution

I connected lead intake to HubSpot, implemented scoring rules in Python and JavaScript, and tested both versions on the same inputs.

System design

The language model proposes field values with quotes from the buyer. Code checks each quote, parses the budget and calculates priority before the workflow updates the CRM.

Tools & components

  • n8n
  • Azure OpenAI
  • HubSpot
  • Python
  • JavaScript

Results & trade-offs

All 10 offline qualification scenarios passed.

Implementation decisions

Two implementations of the rules let me test in Python and run inside n8n Cloud. A parity test checks that the JavaScript port reaches the same decision.

Testing & reliability

A replayed event is ignored once its CRM update succeeds. Uncertain budgets go to review. Offline scenarios cover duplicate leads, revised budgets, existing contacts and requests for a person.

Data handling

Qualification records can contain phone numbers and budget details. A public demonstration should use synthetic contacts and a separate CRM workspace.

Next steps

I would test simultaneous updates to the same lead and expand the Arabic budget fixtures with reviewed, synthetic examples.
